# MikotoUrabeSkin

MikotoUrabeSkin is a custom Minecraft skin texture for players who want to embody the iconic character Mikoto Urabe from Nazo no Kanojo X. This project provides a flat 2D texture map layout (UV skin map) fully unwrapped and formatted as a printable/exportable Minecraft skin template. The texture includes Mikoto's messy black hair, school uniform (white blouse, dark collar, red neckerchief, dark pleated skirt), and her characteristic pale skin and black eyes visible beneath her bangs. The output is a flat 2D texture sheet showing all separated limbs, torso, and head panels laid out on a plain solid/transparent background, fully functional for importing into Minecraft.

## Install

1. Download the MikotoUrabeSkin texture file from the GitHub repository.
2. Open Minecraft.
3. Navigate to the Minecraft skins directory. The location varies depending on your operating system:
   - Windows: `%appdata%/.minecraft/assets/skins/`
   - macOS: `~/Library/Application Support/minecraft/assets/skins/`
   - Linux: `~/.minecraft/assets/skins/`
4. Place the downloaded texture file into the skins directory.
5. In Minecraft, go to your profile settings and select the MikotoUrabeSkin texture.

## Use

1. Launch Minecraft.
2. Go to the skin customization section in your profile settings.
3. Select the MikotoUrabeSkin texture from the available options.
4. Save your changes and enjoy playing as Mikoto Urabe.
